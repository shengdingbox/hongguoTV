# 红果 TV

自家电视使用的非官方红果短剧客户端，与红果官方无关联。**Kotlin 原生 APK**：最低 Android 5.0（API 21），电视遥控器操作，ARM32 / ARM64 / x86 / x86_64 通用。请求签名由自建 openhongguo 签名服务生成（默认公网入口 `http://123.57.172.104:8901`，通过 FRP 转发至飞牛容器，见 [签名服务接入](docs/SIGN_SERVICE.md)），APK 内不再包含签名算法。

**[下载最新版 APK](https://github.com/jycao2/hongguoTV/releases/latest)** · [问题反馈 / 提交 Issue](https://github.com/jycao2/hongguoTV-updates/issues) · [版本记录与构建说明](kotlin-tv/README.md)

> 使用中遇到问题、有功能建议，请到 **[hongguoTV-updates issues](https://github.com/jycao2/hongguoTV-updates/issues)** 提交。该仓库同时承载版本更新与下载，问题与建议统一在那里提出，方便跟进修复与回复。

## 主要功能

应用内更新、手机遥控、手机快传、备份与恢复及局域网扫码辅助功能已移除。安装新版本请下载 APK 后通过系统安装器或 ADB 覆盖安装。

- **浏览**：首页接着看 / 收藏有更新 / 稍后看 / 热门发现横向剧架，随机荐剧一键换一批，漫剧 / 短剧热播榜，24+8 个题材分类浏览，多季剧详情页直接跳季
- **搜索**：漫剧 / 短剧分类型，联想词、搜索历史，键盘 / 联想 / 结果三栏同屏，超长联想词获焦横向滚动显示全名
- **播放**：自动连播、系列剧跨季连播、片头片尾按剧跳过、0.75-2× 倍速、清晰度档位、定时停止、播完推荐；遇到平台未提供标准编码的集数可一键下一集或自动连跳；遥控器按键行为可自定义，遥控 ↑↓ 可选「选集面板 / 直切集数」；全屏播放支持鼠标手势（上滑下一集、下滑上一集、单击呼出控制条）；播放接口持续空响应时自动换匿名设备身份重试
- **手机竖屏浏览**：推荐、新剧日历、真实热搜榜与热点话题，排行榜按内容类型和子榜切换，选中标签自动滚动到可见位置；排行榜与热搜保存本机缓存，重启先展示缓存再联网刷新；详情页逐集显示已看标记。内容和设置支持跟随系统、浅色、深色三种外观，关闭后重新打开恢复标签、搜索草稿、榜单选择和详情页；正在看的剧恢复为上次位置的暂停状态。
- **手机触屏播放**：沿用原有播放器布局与按钮，轻点画面显示原有控制条；支持按钮单次点击、双击暂停 / 播放、拖动进度条定位与上下滑动换集，倍速仍从「播放设置」进入
- **账号**：扫码登录红果账号，观看记录可手动同步到云端，云端记录可随时手动刷新；本机记录与云端记录分区展示，云端记录带角标且只读，切换账号不影响本机数据
- **弹幕**：接入平台官方弹幕源，不透明度 / 字号 / 速度 / 行数可调，表情代码自动展开；支持关键词屏蔽与按剧单独记忆开关
- **收藏**：分组管理、更新自动检查与提示
- **数据**：收藏与本机记录保存在设备，登录后可同步到红果账号；本机观看统计仅存在本地
- **界面**：顶栏固定为「首页 / 搜索 / 排行榜 / 我的」文字导航，选中加粗变色带边框，小屏电视自动紧凑，界面缩放三档（标准 / 大 / 特大）整体调大不变形；设置页左右分栏；深夜影院 / 暖玉白双主题，内置背景风格，全部弹窗统一深色玻璃卡片风格
- **维护**：设置页内置接口自检（首页 / 搜索 / 播放 / 联想连通性一键检测，灰 / 绿 / 红状态标识）

## 工程结构

- `kotlin-tv/`：客户端工程（Kotlin + Android 原生 View + Media3），单测、构建与发布说明见其 README
- `scripts/`：正式包构建与发布脚本
- `deploy/`：匿名装机统计的云函数部署
- `docs/`：接口研究、部署与历史交付资料；版本改动见 [更新日志](docs/CHANGELOG.md)

## 隐私

应用每次启动向自建腾讯云函数发送一次匿名 GET（随机安装 ID + 版本号），用于估算真实装机量；不收集 IP、机型、观看内容或任何账号信息，失败静默。除此之外无任何第三方统计 / 广告 / 崩溃上报 SDK。详见 [隐私与匿名统计](kotlin-tv/README.md#隐私与匿名统计)。
