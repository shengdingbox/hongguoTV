# 红果 TV

非官方红果短剧、漫剧客户端，使用 **Kotlin + Android 原生 View + Media3** 开发，适配 Android TV、电视盒子和安卓手机，支持实体遥控器、键盘、鼠标与手机触屏操作。本项目与红果官方无关联。

**[下载最新版 APK](https://github.com/superhuluwa/hongguoTV/releases/latest)** · **[问题反馈与功能建议](https://github.com/superhuluwa/hongguoTV/issues)** · [原生工程与版本记录](kotlin-tv/README.md)

以下功能说明以当前 `main` 分支源码为准，已发布安装包的功能以对应 Release 说明为准。

## 下载与安装

从 [Release 页面](https://github.com/superhuluwa/hongguoTV/releases/latest) 下载适合设备系统的 APK，安装后联网使用。

| 安装包 | 系统要求 |
| --- | --- |
| 文件名以 `-android8.apk` 结尾 | Android 8.0 及以上，默认版本 |
| 文件名以 `-android5.apk` 结尾 | Android 5.0–7.x 兼容版本 |

APK 不包含 JNI 库，可在 ARM32、ARM64、x86、x86_64 设备上运行，实际视频解码能力取决于设备。

将 APK 拷贝到设备后使用系统安装器安装，也可以通过 ADB 覆盖安装：

```bash
adb install -r APK文件路径
```

更新请下载新版 APK 手动覆盖安装；覆盖安装需保持包名与签名一致，卸载会清除本机数据。当前版本已移除应用内检查、下载与安装更新功能。

## 电视端

- **六个独立入口**：首页、找剧、排行榜、收藏、观看历史、设置；支持遥控焦点导航，小屏布局自动适配。
- **首页自动播放**：大卡片展示当前作品并自动播放，左右切换作品、确认键暂停或继续；进入全集时接着首页播放进度观看。保留接着看、收藏更新、稍后看与热门推荐入口，以及随机荐剧、隐藏不感兴趣内容等操作。
- **找剧与搜索**：遥控器字母和数字键盘、中文联想、搜索历史与结果同屏展示；支持漫剧、短剧切换，以及按类型、主题、设定、背景、受众、时间、状态等条件进行高级筛选。
- **榜单与上新**：漫剧、短剧、AI 剧热播榜，展示名次与热度；支持最新上架时间筛选和 AI 剧分类浏览。
- **详情与选集**：海报、简介和集数分栏展示，支持每组 20 集、跳转集数、多季切换与相关推荐；播放中可打开侧边选集面板。
- **主题与设置**：深夜影院、暖玉白双主题，内置背景风格，标准 / 大 / 特大 / 极大四档界面缩放；设置采用左右分栏布局。

## 手机端

- **竖屏页面**：独立的推荐、排行榜、新剧、搜索和我的页面，提供适合触屏操作的导航、列表与底部弹层。
- **推荐与发现**：推荐流支持分页和下拉刷新；搜索展示联想词、历史、热搜榜与热点话题；排行榜按内容类型和子榜切换，新剧日历按日期浏览。
- **滑动切页**：排行榜与新剧页面支持横向滑动切换，顶部标签随选中项滚动；长列表分批加载，封面及列表数据通过本机缓存复用。
- **触屏播放**：轻点画面切换控制条、双击暂停或播放、拖动进度条定位、上滑下一集与下滑上一集；支持选集弹层和横屏全屏观看。
- **恢复现场**：重新打开时恢复所在页面、滚动位置、搜索草稿、榜单选择与详情；播放现场按上次进度恢复为暂停状态，详情页逐集显示已看标记。
- **外观与方向**：手机外观可跟随系统或固定为浅色、深色；启动方向可跟随系统、强制横屏或强制竖屏，电视端保持横屏。

## 播放与追剧

- **连续观看**：自动连播、系列剧跨季连播、断点续播、按剧跳过片头片尾，以及播完后的推荐。
- **播放偏好**：0.75 / 1 / 1.25 / 1.5 / 1.75 / 2× 倍速，清晰度选择、完整画面 / 等比铺满 / 拉伸铺满；支持全局默认值与本剧播放设置。
- **定时停止**：按分钟或剩余集数设置停止条件，到点暂停并保存进度。
- **缓存后三集**：默认开启，当前集缓冲充足后将后续三集缓存到设备，播放页底部以三段进度条显示缓存进度。切集优先读取已有完整或部分缓存；当前集起播、缓冲不足、设备存储或内存紧张时暂停后台预载，优先保障正在看的内容。
- **播放恢复**：网络故障时支持重新取址和自动重试，解码失败时尝试降低清晰度；平台未提供兼容视频的集数可手动跳过，也可开启自动跳过。
- **官方弹幕**：可调不透明度、字号、移动速度与展示行数，支持表情、关键词屏蔽、同屏去重与按剧记忆开关。
- **收藏与记录**：本机收藏分组、稍后看、观看进度和已看状态，收藏更新自动检查与提示；观看统计保存在本机。
- **红果账号**：使用红果 App 扫码登录，读取并刷新云端观看记录，手动将本机观看进度同步到云端。本机与云端记录分开展示，云端记录带标记，切换账号不影响本机数据。

## 签名模式

默认使用**本地算法**，在设备上完成请求签名并复用本机匿名设备身份。电视和手机均可在「设置 → 算法模式」中打开选择弹框，选择「本地算法」或「远程算法」。选择会保存并立即生效，收藏和观看记录保留。设置页仅展示算法名称。

远程算法模式使用服务的 `/info.deviceProfile` 获取设备参数，并通过 `/sign` 获取签名；POST 请求体以 `body_base64` 原样提交，签名服务需声明 `supportsBodySigning=true`。播放优先使用 `video_tab` GET 接口，沿用现有 CENC 媒体处理。

本地算法模式的播放已接入 V5 协议：优先调用 `/novel/player/multi_video_model/player/v1`，本机对 gzip 请求体生成 Helios / Medusa 签名，直接解析当前集的多档视频地址与内容密钥。正式播放、预取和离线缓存共用新取址链路，继续使用现有 Media3 播放器和 CENC 媒体解密。

## 常用操作

| 场景 | 操作 |
| --- | --- |
| 电视列表页 | 方向键移动焦点，确认进入，返回回到上一级 |
| 电视首页预览 | 左右换剧，确认暂停或继续，从「播放全集」进入播放器 |
| 电视播放页 | 确认暂停或播放，左右快退或快进，上下打开更多操作或选集 |
| 播放快捷面板 | 长按菜单键调整清晰度、倍速、弹幕等设置 |
| 鼠标播放 | 点击画面切换控制条，拖动进度条，上滑下一集、下滑上一集 |
| 手机播放 | 双击暂停或播放，拖动进度条，滑动换集，点击选集或全屏按钮 |

遥控器快进步长、菜单键行为及上下键是否直接切集，可在「设置 → 播放与观看 → 遥控器按键」中调整。播放中返回会先收起面板或控制条，再退出播放器。

设置页提供缓存清理、恢复隐藏推荐、接口自检、运行日志和异常日志查看；版本号显示在设置页底部。手机遥控、手机快传、备份与恢复、局域网扫码输入与传图功能已移除，红果账号扫码登录仍可使用。

## 本地构建

准备 JDK 17、Android SDK 36，并配置 `ANDROID_HOME` 或工程的 `local.properties`。在仓库根目录执行以下命令构建开发包，无需正式发布密钥：

```bash
./kotlin-tv/gradlew -p kotlin-tv :app:assembleDebug
```

输出文件为 `kotlin-tv/app/build/outputs/apk/debug/app-debug.apk`。默认最低系统版本为 Android 8.0；构建 Android 5.0–7.x 兼容包时添加属性：

```bash
./kotlin-tv/gradlew -p kotlin-tv -PHONGGUOTV_MIN_SDK=21 :app:assembleDebug
```

正式包签名配置与构建方式见 [原生工程说明](kotlin-tv/README.md#构建)。开发包与正式包签名不同，不能直接互相覆盖安装。正式版由维护者在本地手动构建签名包，推送代码不会自动发版。

## 数据与隐私

收藏、观看进度、已看状态、搜索历史和设置保存在本机。登录红果账号后，可以主动读取云端记录或手动上传本机观看进度；视频缓存保存在设备，用于本机播放。

应用每次进程启动发送一次匿名统计请求，内容仅为随机安装 ID、应用版本名和版本号，用于估算装机量与活跃量，不携带观看、收藏或账号信息。请求失败静默丢弃，不阻塞启动。运行日志与异常记录保存在本机，应用不包含第三方统计、广告或崩溃上报 SDK。
