# 红果 TV

非官方红果短剧、漫剧客户端，使用 **Kotlin + Android 原生 View + Media3** 开发。一个 APK 同时适配 Android TV、电视盒子和安卓手机，支持遥控器、键盘、鼠标与触屏操作。

**[下载最新版 APK](https://github.com/superhuluwa/hongguoTV/releases/latest)** · **[问题反馈与功能建议](https://github.com/superhuluwa/hongguoTV/issues)** · [更新日志](docs/CHANGELOG.md)

当前实现直接接入红果官方业务接口，浏览、搜索、榜单、详情和播放在端内完成；默认本地算法模式不需要用户另行搭建内容服务。本项目与红果官方无关联。

> 本说明以当前 `main` 分支源码为准。已发布安装包的功能以对应 Release 说明为准；文档目录中的早期调研、交付记录和更新日志不代表当前功能现状。

## 下载与安装

安装包发布在 [Release 页面](https://github.com/superhuluwa/hongguoTV/releases/latest)，电视、电视盒子和安卓手机共用同一个 APK，下载后安装即可。浏览和首次播放需要联网；已经完整缓存的剧集可从离线缓存入口本地播放。

| 安装包 | 系统要求 |
| --- | --- |
| `hongguotv-kotlin-<版本号>.apk` | Android 8.0（API 26）及以上，当前默认版本 |
| 历史版本中以 `-android8.apk` 结尾的文件 | Android 8.0 及以上，与上一行内容一致 |
| 历史版本中以 `-android5.apk` 结尾的文件 | Android 5.0–7.x 兼容版本，仅部分历史版本提供 |

- **不区分 CPU 架构**：项目不含 ARM、x86 等架构专用的 JNI 库，可在 ARM32、ARM64、x86、x86_64 设备上运行，实际视频解码能力取决于设备。
- **统一包名**：应用包名为 `com.huluwa.nativeapp`；维护者发布的正式包使用同一份签名，可直接覆盖升级。
- **附件说明**：最新 Release 的 Assets 只提供 APK；部分历史 Release 另附 `build-info.json` 与 `SHA256SUMS`，可用于核对版本号和文件校验值。
- **权限精简**：应用只声明网络访问和网络状态权限，不要求存储、定位、通讯录等权限。视频和离线内容保存在应用自己的存储空间中。

安装方式：

1. **电视与电视盒子**：把 APK 拷贝到 U 盘并插入设备，用系统文件管理器或自带安装器打开；首次安装需在系统设置中允许「未知来源应用」，或对文件管理器开启「允许安装未知应用」。
2. **安卓手机**：下载后直接点击 APK 安装，同样需要允许浏览器或文件管理器安装应用。
3. **ADB 安装或覆盖安装**：

```bash
adb install -r hongguotv-kotlin-<版本号>.apk
```

更新时下载新版 APK 手动覆盖安装，覆盖安装需保持包名与签名一致。从开发包切换到正式包，或卸载后重新安装，需要先卸载旧版；卸载会清除本机的收藏、观看记录、设置和离线内容。当前版本已移除应用内检查、下载与安装更新功能。

## 电视端

- **首页推荐**：大卡片展示当前作品并自动播放，左右切换作品、确认键暂停或继续；进入全集时延续首页播放进度。保留接着看、收藏更新、稍后看和热门推荐，并支持随机荐剧、隐藏不感兴趣的内容。
- **找剧与搜索**：遥控器字母和数字键盘、中文联想、搜索历史与结果同屏展示；支持漫剧、短剧切换，以及按类型、主题、设定、背景、受众、时间和状态等条件筛选。
- **榜单与上新**：展示漫剧、短剧和 AI 剧榜单的名次与热度，电视榜单使用红果官方接口；支持子榜切换、最新上架时间筛选和 AI 剧分类浏览。
- **详情与选集**：海报、简介和集数分栏展示，每组 20 集，支持跳转集数、多季切换和相关推荐；播放中可打开侧边选集面板。
- **追剧管理**：独立收藏、观看历史和设置页面，支持收藏分组、收藏更新检查、记录管理和稍后看。
- **界面外观**：深夜影院、暖玉白双主题，内置背景风格；标准 / 大 / 特大 / 极大四档界面缩放，设置采用左右分栏布局。

## 手机端

- **独立触屏布局**：推荐、排行榜、新剧和我的四个主页面，搜索入口位于推荐页；不是把电视焦点界面简单缩放到手机上。
- **推荐与搜索**：推荐流分页加载和下拉刷新；搜索提供联想词、搜索历史、热搜榜与热点话题，并支持搜索合集及其分集。
- **榜单与新剧**：按内容类型和子榜切换，榜单首屏使用明确的子榜选择；新剧日历按日期浏览。排行榜和新剧支持下拉刷新、横向滑动切换标签与分批加载。
- **详情与返回**：支持收藏、选集、评分展示和离线缓存入口；封面使用共享元素过渡，返回列表时尽量保留原滚动位置和已加载封面。
- **触屏播放**：轻点画面切换控制条、双击暂停或播放、拖动进度条定位、上滑下一集与下滑上一集；支持选集弹层和横屏全屏。
- **恢复现场**：重新打开时恢复所在页面、滚动位置、搜索草稿、榜单选择和详情；播放现场按上次进度恢复为暂停状态，详情页逐集显示已看标记。
- **外观与方向**：手机外观可跟随系统或固定为浅色、深色；启动方向可跟随系统、强制横屏或强制竖屏，电视端保持横屏。

## 播放、缓存与离线观看

### 播放与追剧

- **连续观看**：自动连播、系列剧跨季连播、断点续播、按剧跳过片头片尾，以及播完后的推荐。
- **播放偏好**：0.75 / 1 / 1.25 / 1.5 / 1.75 / 2× 倍速，480P / 720P / 1080P 清晰度上限，完整画面 / 等比铺满 / 拉伸铺满；设置页保存全局默认值，播放页临时调整只在本次播放会话中生效。片头片尾跳过时间按剧本机保存。
- **定时停止**：按分钟或剩余集数设置停止条件，到点暂停并保存进度。
- **官方弹幕**：可调不透明度、字号、移动速度与展示行数，支持表情、关键词屏蔽和同屏去重；开关与显示参数全局保存。
- **异常恢复**：网络故障时支持重新取址和自动重试，解码失败时尝试降低清晰度；平台未提供兼容视频的集数可手动跳过，也可开启自动跳过。

### 自动预缓存与手动离线缓存

这是两种不同用途的缓存，不应混为一谈：

| 方式 | 用途 | 管理方式 |
| --- | --- | --- |
| 播放预缓存 | 默认开启，当前集缓冲充足后缓存后续三集，改善起播和切集体验 | 自动调度，播放页以分段进度显示后续缓存状态 |
| 手动离线缓存 | 按剧选择需要的集数，长期保留并集中管理，供应用内本地播放 | 手机详情页进入缓存选集，在「我的 → 离线缓存」查看任务和已缓存内容 |

自动预缓存优先保障正在观看的剧集：当前集起播、缓冲不足、设备存储或内存紧张时会暂停后台任务，恢复后再继续。完整缓存和有效的部分缓存可被播放与切集直接复用；未缓存完整的内容不能视为离线视频。该缓存池上限为 500 MiB，每剧最多保留 5 集，缓冲充足时最多三路下载；可用空间低于 1 GiB 或设备内存受限时停止预缓存。

手动离线缓存支持点选或全选分集、追加缓存、查看总进度和各集进度、暂停或继续任务、失败重试、删除内容，以及调整下载并发数。默认同时下载 3 集，可设为 1–5 集。下载仍需要网络，支持断点续传和退出应用后的任务恢复；它不是独立系统下载服务，退出页面不会取消任务。下载完成后可直接使用本地媒体，不依赖原在线地址继续有效。下载选集每组展示 60 集，已缓存内容的本地选集每组展示 200 集。缓存内容仅供应用内播放，不提供通用视频文件导出功能。

自动预缓存池与手动离线库分别管理；普通清理缓存不会删除离线库。当前手动离线缓存入口位于手机竖屏界面。

## 收藏、记录与红果账号

- **本机数据**：收藏分组、稍后看、观看进度、逐集已看状态和观看统计保存在当前设备；支持收藏更新自动检查与提示。
- **扫码登录**：使用红果 App 扫码登录，可读取并刷新云端观看记录。登录凭证在应用私有空间中加密保存，受支持的 Android 版本使用 Android Keystore 管理密钥。
- **手动同步**：可将本机观看进度主动同步到云端，不是后台自动双向同步。
- **数据分离**：本机与云端记录分开展示，云端记录带标记；切换账号不会覆盖本机数据。
- **同步边界**：红果账号功能针对观看记录和进度，不代表本机收藏、稍后看、设置或离线文件会自动同步到其他设备。

## 签名模式

默认使用**本地算法**，在设备上完成请求签名并复用本机匿名设备身份。电视和手机均可在「设置 → 算法模式」中选择「本地计算」「远程计算-unidbg」或「远程计算-frida」，选择保存后立即生效，收藏和观看记录保留；设置页仅展示算法名称。

- **本地计算**：播放优先使用 V5 协议 `/novel/player/multi_video_model/player/v1`，本机生成 Helios / Medusa 签名并处理 gzip 请求体，直接解析当前集的多档视频地址与内容密钥。正式播放、预取和离线缓存共用取址链路，使用 Media3 播放及 CENC 媒体处理。
- **远程计算-unidbg**：签名交给 [openhongguo-signer](../openhongguo/signer/README.md) —— 在 unidbg 里运行 App 自带的 `libmetasec_ml.so`，通过 `POST /feature-hash` 把完整 URL 与请求体字节换成六个签名头。设备身份仍由本机匿名注册，与本地计算共用同一份档案。地址为 `http://taihe.678120.cn:8028`（菜鸡公网，经飞牛 `frpc-caiji` 转发到局域网 `192.168.3.83:9876`），服务开启 `SIGNER_TOKEN` 时需在 `UnidbgSigner` 里填入相同的 token。播放优先使用 `video_tab` GET 接口。
- **远程计算-frida**：使用内置的明文 HTTP 远程服务，通过 `/info` 获取设备参数、通过 `/sign` 获取签名；POST 请求体以 `body_base64` 原样提交，服务需声明 `supportsBodySigning=true`。播放优先使用 `video_tab` GET 接口，沿用现有媒体处理链路。该模式依赖此第三方服务，不提供自定义服务地址设置；远程模式的可用性与传输安全边界不同于本地算法。

本地计算是默认且无需额外部署的方式；两种远程计算模式都依赖各自内置的签名服务，且不适用本机 V5 播放取址路由。三种模式都要求上游接口、签名协议和设备档案可用。

### 媒体兼容边界

播放器面向普通 MP4、分片 MP4 及已支持的 CENC 加密媒体，不是支持任意流媒体协议的通用播放器。CENC 媒体要求索引位于文件开头，并依赖 CDN 正确支持 Range / 206 分段读取；索引大小和样本数量也有限制。遇到无法取址、视频索引位置不符或设备缺少对应解码器时，即使能够安装 APK，也不保证所有内容都能播放。

## 本地构建与发布

### 环境要求

- JDK 17。
- Android SDK 36，以及 Android SDK Platform 36 和 Build-Tools 36.0.0。
- 配置 `ANDROID_HOME`，或在 `kotlin-tv/local.properties` 中设置 `sdk.dir`。

在仓库根目录构建开发包，无需正式发布密钥：

```bash
./kotlin-tv/gradlew -p kotlin-tv :app:assembleDebug
```

输出文件为 `kotlin-tv/app/build/outputs/apk/debug/app-debug.apk`。默认最低系统版本为 Android 8.0；构建 Android 5.0–7.x 兼容包时添加属性：

```bash
./kotlin-tv/gradlew -p kotlin-tv -PHONGGUOTV_MIN_SDK=21 :app:assembleDebug
```

核心模块测试与 Android Lint 可分别执行：

```bash
./kotlin-tv/gradlew -p kotlin-tv :core:test
./kotlin-tv/gradlew -p kotlin-tv :app:lintDebug
```

`app/build.gradle.kts` 当前默认 `versionName` 为 `0.30.10`、`versionCode` 为 `12`；可通过 `HONGGUOTV_VERSION_NAME` 和 `HONGGUOTV_VERSION_CODE` 覆盖。正式签名从 `kotlin-tv/keystore.properties` 或相应的 `HONGGUOTV_*` 环境变量读取，密钥文件不进入仓库。

### 发布说明

正式包由维护者的打包服务器构建并签名，开发包与正式包签名不同，不能直接互相覆盖安装。在仓库根目录执行以下命令，可将 Debian 打包服务器上最新成功的 APK 发布到 GitHub Release：

```bash
bash scripts/publish-tv-release.sh
```

也可以在 [GitHub Actions](https://github.com/superhuluwa/hongguoTV/actions/workflows/release.yml) 点击 **Run workflow** 发布。该流程读取已经完成的构建，不重新编译或修改签名；仅将 `hongguotv-kotlin-<版本号>.apk` 上传到 Assets，标签为 `build-v<versionName>-<versionCode>` 并指向实际构建的源码提交。推送代码不会自动发版。

认证、指定构建任务、模拟执行、断线恢复和 self-hosted runner 配置见 [发布说明](docs/GITHUB_RELEASE.md)。

### 发布包裁剪

Release 构建启用 R8 代码压缩和资源裁剪，播放器只保留普通 MP4 与分片 MP4 提取器。Glide 4.16.0 的默认组件注册由 R8 规则移除，静态封面所需的网络、解码和磁盘缓存组件在 `ArtworkGlideModule` 中显式注册；升级 Glide 时需同步维护该模块与 `app/proguard-rules.pro` 中的方法签名。

## 数据与隐私

收藏、观看进度、已看状态、搜索历史和设置保存在本机。目录快照、详情评分、封面和视频也可能在设备上缓存，用于加快展示或播放。登录红果账号后，可主动读取云端记录或手动上传本机观看进度；离线视频保存在设备上，用于应用内播放。

应用每次进程启动发送一次匿名统计请求，内容仅为随机安装 ID、应用版本名和版本号，用于估算装机量与活跃量，不携带观看、收藏或账号信息。请求失败静默丢弃，不阻塞启动。运行日志与异常记录保存在本机，应用不包含第三方统计、广告或崩溃上报 SDK。

## 问题反馈

问题与功能建议统一提交到 **[本仓库 Issues](https://github.com/superhuluwa/hongguoTV/issues)**。请尽量提供：

- 设备型号、Android 版本及应用版本号。
- 复现步骤、具体剧名与集数，以及相关截图。
- 播放或启动异常时，附设置页中的运行日志或异常日志，并在提交前去除个人信息。

内容、接口、签名或播放可用性可能随上游服务变化；遇到播放异常时，可先使用设置页的接口自检和日志定位。设备能否解码特定清晰度或编码，还取决于其硬件和系统解码器。
